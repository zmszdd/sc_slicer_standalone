# 四指标客观化口径定义（2026-11-08）

本文件冻结“合理、客观”的指标口径。任何对外指标必须标注属于哪条口径，
不把构造性数字当成盲测结论。

> **权威准确率口径（2026-11-09 更新）**：判例 invalid 全量普查（91 例中 75 例
> 可评测）为准——TP=43，FP=15，准确率 **43/58 = 74.1%**（95% CI 61.6%–83.7%），
> FP 率 15/75 = 20.0%。之前的 30 例小样本盲测 87.8% 与构造负样本 100% 均为
> 历史口径，不得作为对外精度。15 个 FP 全部是“机制忠实、判例裁决对象错位”的
> 口径 FP，12 个集中在 SukukFi dust/捐赠 DoS 家族，见
> `tools/stage3/evaluation/metrics/FP_ATTRIBUTION_20261108.md`。

## 1. 主线漏斗（案例级，分母=全输入 105）

| 层 | 定义 | 当前值 |
| --- | --- | ---: |
| 阶段一 flatten | 有 `contract.flattened.t.sol` | 105/105 = 100% |
| 阶段二 spec 非空 | `stage3-spec.json` claims 非空 | 97/105 = 92.4% |
| 阶段三 动态终态 | 任一 claim 有 `violation_reproduced`/`not_reproduced` | 58/105 = 55.2% |
| 阶段三 复现(机械) | ≥1 claim `violation_reproduced` | 44/105 = 41.9% |
| 判例净化 TP | 判例 valid/fixed/wontfix 且复现 | 43 例（另 1 例为判例 invalid，计 FP） |

规则：漏斗每一层都是**一等指标**，覆盖损失（105−58=47）按原因分层报告，不得
合并成“阻塞案例”单数字。

## 2. 召回：三条线，缺一不可

- 端到端召回 = 判例净化 TP / 判例相关样本 = 43/101 = 42.6%
  （95% CI 33.4%–52.3%；相关样本 = 判例 valid/fixed/wontfix 的 finding）。
- 可评测召回 = 判例净化 TP / 判例相关动态样本 = 43/57 = 75.4%
  （95% CI 62.9%–84.8%；条件口径，需同时报告分母）。
- 项目级召回 = 至少复现 1 个 finding 的项目 / 项目总数 = 16/20 = 80.0%
  （对抗案例内相关性，是最诚实的“项目泛化”指标）。

## 2.5 四指标（判例锚定，2026-11-09 冻结）

完成率、召回、准确率、F1 全部落在同一混淆矩阵上，不再混用构造负样本 FP=0：

| 指标 | 值 | 分子 / 分母 |
| --- | ---: | --- |
| 完成率 | 90.5% | 95 例 stage3 done / 105（95% CI 83.4%–94.7%） |
| 动态终态率(覆盖率) | 55.2% | 58 例动态终态 / 105 |
| 召回(端到端) | 42.6% | TP=43 / 判例相关样本 101 |
| 召回(可评测) | 75.4% | TP=43 / 判例相关动态样本 57 |
| 准确率(判例锚定) | 74.1% | TP=43 / (TP+FP=58) |
| F1(端到端) | 0.541 | 调和(74.1%, 42.6%) |
| F1(可评测) | 0.748 | 调和(74.1%, 75.4%) |
| 准确率(影响门后/漏洞级) | 93.5% | 排除 12 例影响不足 FP，CI 82.5%–97.8% |
| F1(影响门后/端到端) | 0.585 | 调和(93.5%, 42.6%) |
| F1(影响门后/可评测) | 0.835 | 调和(93.5%, 75.4%) |

混淆矩阵：`valid/fixed/wontfix(+)` TP=43 / FN=58（合计 101）；`invalid(-)`
FP=15 / TN=60（合计 75）。FP 采自判例 invalid 独立负样本池，TP/FN 采自
判例相关正样本池，两池患病率不同，不跨池假设等患病率。

## 3. 准确率：唯一对外口径是判例全量普查

- 判例全量口径（权威）：负样本来自 `judge_ground_truth.json` 中判例 `invalid`
  的独立 finding（91 例，75 例可评测）。这是当前**唯一可对外引用**的准确率。
  - 当前值：TP=43 FP=15，准确率 74.1%，95% CI 61.6%–83.7%，FP 率 20.0%。
- 端到端天花板：判例相关样本 101 中 7 例为机制天花板（缺参考补丁 / 不可动态
  表达），扣除后端到端召回上限 94/101=93.1%；其余 51 例 FN 为可恢复质量损失。
  - FP 归因：15 个 FP 全为口径 FP（机制忠实、判例裁决对象错位），12 个集中在
    SukukFi dust/捐赠 DoS 家族。
- 构造负样本口径（仅内部一致性自检）：负样本来自“已复现 claim → 语义修复 →
  fix_poc 翻转”，FP=0 是设计使然，只能证明一致性，不能证明对外精度。
  - 当前值：机械 TP=44 FP=0 TN=78，100%（判例净化 TP=43，另 1 例机械复现为判例 invalid；TN 已并入 `goldset_v2_neg_expand` 的 34 例新负样本，全为 `violation_not_reproduced`）。
- 漏洞级准确率（二级口径，仅作归因，不作为对外主口径）：从判例 FP 中显式
  剔除“机制忠实但影响不足”的 dust/捐赠 DoS 家族（SukukFi 12 例，清单见
  `tools/stage3/evaluation/metrics/impact_insufficient_cases.json`），用于回答
  “剩余 FP 是否仍是同一机制性缺陷，而非影响判定的语义错位”。
  - 当前值：TP=43，剩余 FP=3，漏洞级准确率 43/46=93.5%（95% CI 82.5%–97.8%）。
  - 说明：剔除仅改变二级归因，不改动权威一致口径的 74.1%；15 个 FP 均被审为
    “机制忠实、判例对象错位”，无 binding/probe/compile 机制性误报。
- 历史盲测口径（作废）：30 例小样本曾得 87.8%，被全量普查修正为 74.1%，仅留档。

## 4. 样本独立性

- 105 例只覆盖 20 个项目、TP 落在 16 个项目；案例间高度相关，不能把 105 当
  独立样本。项目级才是有效样本量。
- 目标：随机扩容抽样到 ≥40 个项目、负样本独立根因 ≥40。

## 5. 输出与脚本

- 生成器：`tools/stage3/cli/metrics_report.py`（漏斗+覆盖损失+项目级+四指标多口径）。
- 判例锚定：`tools/stage3/evaluation/metrics/judge_anchor.py`（含 FP 项目家族分布、
  端到端天花板 `recall_end_to_end_ceiling`）。
- 一键四指标：`python main.py stage3 full-flow ...`（正样本 eval → 负样本 → 判例锚定 → metrics_report）。
- 报告：`tools/stage3/evaluation/metrics/metrics_report_105.json` / `.md`。
