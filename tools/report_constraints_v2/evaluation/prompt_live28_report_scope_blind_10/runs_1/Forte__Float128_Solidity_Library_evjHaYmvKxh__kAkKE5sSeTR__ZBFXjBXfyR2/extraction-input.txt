[H-3] Missing validation for negative inputs in `Ln::ln`

## Finding description and impact

The Natural Log of a negative number is `undefined` as a negative number cannot be expressed as a power of positive base ( e=2.718 in this case) 

but the `Ln.sol`'s `ln` function returns values for negative inputs same as their positive counterparts

The main impact is that key mathematical invariant is broken.

This will result in unexpected results for functions which depend on this function

## Recommended mitigation steps

Check if the passed `packedFloat` input is negative number at the start of the function and revert if it is negative to mitigate the issue (as done in `Float128::sqrt` function)

Make the following changes in `Ln::ln` function

1. In `Ln.sol` declare a new constant state variable 

2. Make the following changes in `Ln::ln` function
