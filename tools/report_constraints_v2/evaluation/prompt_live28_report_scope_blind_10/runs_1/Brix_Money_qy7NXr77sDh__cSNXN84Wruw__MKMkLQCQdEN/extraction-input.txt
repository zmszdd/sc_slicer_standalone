Permissionless rebalance lets anyone drain fast-access buffer to custodian

## Finding description and impact
`rebalanceFunds` is `external` and unprotected. Any caller can sweep all buffer funds above `targetBufferPercentageBPS` to the off-chain custodian, at zero cost, immediately after each mint/top-up. An attacker can repeatedly drain the buffer to the minimum (or lower if target is small), forcing redemptions onto the slow custodian path and defeating the “fast access” guarantee.

## Recommended mitigation steps
Restrict `rebalanceFunds` to an authorized role (admin/keeper), or add guardrails such as a minimum on-chain buffer that cannot be swept, rate limits, or checks that only trusted actors can initiate rebalances.
