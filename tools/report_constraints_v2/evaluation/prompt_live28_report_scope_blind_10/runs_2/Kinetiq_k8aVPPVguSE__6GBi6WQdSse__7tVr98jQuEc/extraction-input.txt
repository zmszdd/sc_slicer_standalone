Unable to Send Withdrawal Funds to StakingManager

## Finding description and impact

Unable to send the StakingManager contract the native token HYPE without triggering the stake() function. This makes it impossible `confirmWithdrawals` since the contract will automatically stake funds when they are withdrawn from the validator.


SIDE NOTE: This was undetected in the tests because the Foundry cheat code `deal` was used to transfer HYPE which did not trigger the `receive` function of the contract.

## Recommended mitigation steps

An easy fix is to add a payable function like `depositWithdrawalFunds` that will accept funds withdrawn from a validator. No other logic changes need to be made.
