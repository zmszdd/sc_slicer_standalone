# semantic-live-21 冻结来源复测

## 方法

- 复用 semantic-live-20 同批复测的冻结来源输入，对 9 份有完整 `impact-applicability.json` 的报告逐 `(Impact, I, P 来源集)` 生成规则；共 52 组。
- Olas 缺少适用性卡，不能冻结来源，因此跳过。
- 使用 semantic-live-21、`deepseek-flash`。规则生成后运行 P/I/V 来源与整体关系审查；失败时按失败角色进行一次受限公式修复，再审查。
- 未重新提取或选择 P/I/V 来源。该轮模型调用 189 次。

## 结果

| 项目 | 结果 |
|---|---:|
| 冻结来源组 | 52 |
| 规则生成 | 46/52 |
| 无可用规则 | 6/52 |
| 生成后完整忠实度通过 | 21/52 |
| 忠实度失败 | 24/52 |
| 忠实度审查不可用 | 1/52 |
| 已生成规则中的完整审查通过率 | 21/46（45.7%） |

来源逐项审查中，P 失配 0/82，I 失配 6/45，V 失配 1/45。45 份完成的整体 P/I/V 关系审查中，21 份一致、9 份减弱、15 份不一致；另有一份审查不可用。

52 组中有 42 组进入过一次受限修复。修复后最终通过 11 组、仍失败 24 组；其余为无规则或审查不可用。修复过程按审查角色收窄字段，并把模型擅自改动的非授权顶层字段恢复到上一份已审查计划。

## 与同来源 live-20 复测对照

| 版本/运行 | 生成规则 | 完整审查通过 | 完整审查通过 / 52 |
|---|---:|---:|---:|
| live-20（首次同来源配对） | 34 | 5 | 9.6% |
| live-21（加入 I 隔离与角色化修复） | 46 | 21 | 40.4% |

该结果支持继续保留 live-21 的 I 隔离要求和角色化局部修复：生成率及完整审查通过数均提高。来源固定排除了上游 P/I/V 选择变化，但模型每轮重新采样，因此这是方向性复测，不是完全确定的因果估计。

I 的单项公式映射仍未解决：6 个 I 失配包括循环恒真谓词、颠倒时间关系、遗漏 pending-until-read 条件，以及把零供应条件错误地绑定到资产存在或漏洞后果。整体关系仍有 24/45 未通过或减弱，当前下一步应围绕 I 与 V 的关系映射继续改进，并保留失败审查结果，不得通过放宽判定来提升计数。

审查不可用的一例是 `pool_exposed_to_continual_attack`：审查模型返回了允许枚举之外的 verdict。计数中将其单列为不可用，没有计为失败或通过。
