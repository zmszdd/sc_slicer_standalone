Two Equally packed negative floats incorrectly evaluated as unequal by `le` function when one of them uses L Mantissa

## Finding description

The [`Float128::le`](https://github.com/code-423n4/2025-04-forte/blob/4d6694f68e80543885da78666e38c0dc7052d992/src/Float128.sol#L899) function is developed to check if in the given of the two packed floats, the former is lesser than or equal to the later.

However, there is an issue which arises when both of the given packed floats are negative, i.e, `MANTISSA_SIGN` set as negative, and, any one of the given packed floats contains a L Mantissa, the function returns false even though the given two packed values are inherently the same. 
This happens due to the way we determine the `retVal` via a greater than check `gt(aMan, bMan)`.

It is not ideal because a `less than equal to` function should also consider when two packed floats are equal, which is lacking here.



## Impact

1. Undesired behaviour shown here would lead to returning a false for a completely equal fixed floats in theory.
