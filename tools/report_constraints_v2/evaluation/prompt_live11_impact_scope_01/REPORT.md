# semantic-live-11 显式 Impact 区域盲测

## 设计

在任何模型调用前，从精确提交语料中冻结 10 份未见报告。按 case ID、报告哈希和规范化输入哈希排除历史样本；选择时不检查 Impact 区域是否存在或包含什么。输入长度为 600–4500 字节，每个批次 5 例。冻结清单及代码、提示哈希见 `SELECTION.json`。

使用 DeepSeek Flash、`semantic-live`、提取和规则化各重试一次、精简形式化输入、`continue-on-review` 与 `signals`。提取共记录 105 次模型调用。6 份候选通过报告另做两阶段同模型族忠实度盲审；这不是独立人工金标准。

## 结果

| 指标 | 结果 |
| --- | ---: |
| 冻结并运行报告 | 10/10 |
| 候选检查通过 | 6/10 (60%) |
| 来源越界校验拒绝 | 2/10 (20%) |
| 产出规则评估文件 | 8/10 |
| 识别影响项（仅限这 8 例） | 27 |
| 完整 P/I/V 的影响项 | 11/27 (40.7%) |
| 所有已识别影响项均完整的报告 | 2/8 (25%) |
| 候选项盲审忠实 / 弱化 / 不忠实 | 3 / 3 / 0（共 6 例） |

被拒绝的两例均因生成的影响项引用了明确标注 Impact 区域之外的证据，在规则化前被拦截；它们没有进入 27 项分母。其余 8 例里，另外 2 例状态为 `needs_review`。候选通过数不代表全报告影响项都已规则化：6 个候选通过报告里只有 2 个覆盖了模型自己识别出的全部影响项。

盲审共评 11 条候选公式的 P/I/V：P 为 10 项完全支持、1 项部分支持；I 为 8 项完全支持、3 项部分支持；V 为 9 项完全支持、2 项部分支持。三个“弱化”报告的问题主要是条件、范围或限定信息没有完整保留。完整逐项理由保存在 `FAITHFULNESS_CANDIDATES.json`。

## 离线重放

零模型调用重放验证了 8/8 份已有规则产物；两份被来源边界拒绝的报告没有产物，重放不适用。详见 `OFFLINE_REPLAY.json`。

## 判断

新边界在这组样本上确实拦住了 Impact 区域外证据，但规则化覆盖仍有限：27 个已识别影响项中 11 个得到完整 P/I/V，且 6 个候选通过中有一半仍有未完整规则化的已识别影响项。盲审也发现 3/6 候选报告存在表达弱化。故本轮支持“证据边界能执行且可重放”，尚不足以证明阶段二整体效果稳定提升，也不能推断对报告影响项的召回率；样本只有 10 份，审阅器与生成器属于同一模型族。
