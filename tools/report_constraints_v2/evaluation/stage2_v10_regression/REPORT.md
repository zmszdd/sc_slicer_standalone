# 阶段二改动定向回归与冻结集复跑

## 运行范围

对上轮待处理影响项或盲审弱化的 41 份报告做定向回归，并在同一冻结 50 例上重复运行。生成器与辅助盲审器均为 DeepSeek Flash；评审器与生成器同属一个模型家族，盲审结果只能作为辅助信号。运行参数、样本选择哈希和当前代码哈希分别记录在 `targeted_v2/RUN_METADATA.json` 与 `frozen50_repeat/RUN_METADATA.json`。初次定向尝试因提示词契约检查失败而未调用模型，保留在 `targeted/`；本报告只统计恢复契约后的 `targeted_v2/`。

## 结果

| 指标 | 定向回归 | 冻结 50 例 | 上轮冻结 50 例 |
| --- | ---: | ---: | ---: |
| 候选检查通过 | 8/41 (19.5%) | 12/50 (24.0%) | 19/50 (38.0%) |
| 影响项完整规则化 | 66/134 (49.3%) | 91/159 (57.2%) | 81/137 (59.1%) |
| 通过候选的盲审忠实 | 5/8 (62.5%) | 4/12 (33.3%) | 8/19 (42.1%) |

定向集通过数上轮为 11/41，本轮为 8/41。冻结集对照中，10 例从通过变待审、4 例从待审变通过、1 例从通过变拒绝、1 例从待审变拒绝，其余状态不变。影响项计数来自模型识别结果，两个版本识别的总数不同，完整率不代表相对人工清单的召回率。

## 拒绝与未通过原因

冻结集两例被拒绝的报告均被判断为“叙述充分”，拒绝由 P/I/V 候选的可行性检查触发：

- `SukukFi_syLyTBz5KNA__x8fhQug5RF4__qYjoqF9WCdt`：P 中将同一 `pending_assets` 同时设为 100 和 50，导致前提不可满足；I 与 V 也都在“用户仍有待处理存款且在 active set”条件下给出不相容结论，使 P∧V 检查为 UNSAT。具体场景步骤没有被转换成区分“先前已完成的 100”与“后来新增的 50”的状态变量。
- `Virtuals_Protocol_hzMS6ZZkBTg__uRCNRZgiUjz__j6HuVHjfaBC`：多个影响项把同一负向标志同时作为 P 与其否定，形成矛盾前提；对 Elo 更新方向的 I/V 也未正确编码，因而 P、I、V 的可行性检查均为 UNSAT。生成内容未保留报告中对两方评分变化方向的具体关系。

定向回归中另有一例 `GTE_Spot_CLOB_and_Router_qa8y3zjgyCn__LDE4mUbttzn__ZAZAHDZ5aHT` 被拒绝：报告虽叙述充分，但两个影响项的安全性质可行性检查失败（`safety_feasibility`）；这表明问题集中在安全条件的构造/绑定，需检查是否把期望性质误作场景前提。另有一例 `Covenant_d4uY8y2AMSs__XdXZVhfNnGC__dNeEkDRLtsN` 在输入筛查阶段停止，缺少触发动作、直接影响和安全关系依据，不属于形式化拒绝。总体上，充分叙述并不自动保证可规则化；当前瓶颈包括状态/时间步骤表达、符号绑定和安全关系与影响关系的分离。

## 结论

本轮未证明整体提升可复现：定向集通过率下降；冻结集候选通过率由 38% 降至 24%，完整影响项比例由 59.1% 降至 57.2%，盲审忠实率在本轮通过项中为 4/12。虽然完整规则化影响项绝对数从 81 增到 91，但模型同时识别的影响项从 137 增到 159，因此比例下降。定向集 5/8 的忠实盲审也基于小样本且评审器与生成器同源，不能视为独立验证。

建议把失败首先定位到阶段二内部：对多步骤报告显式区分状态时点/实体变量，防止同一符号被赋予互斥取值；将报告给出的安全性质与漏洞造成的直接影响分别编码，再用数值和方向约束校验二者关系。此处结论仅限阶段二提取与规则化评估；不涉及阶段三修复生成或消融实验。
