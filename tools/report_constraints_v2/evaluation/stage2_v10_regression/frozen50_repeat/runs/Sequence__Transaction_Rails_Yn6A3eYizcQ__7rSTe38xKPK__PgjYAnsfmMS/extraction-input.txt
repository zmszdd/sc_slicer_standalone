TrailsRouter injectAndCall lets any caller drain pooled ERC20 balances

The router openly exposes `injectAndCall`, which simply forwards whatever ERC20 balance already sits on the router (`_getSelfBalance(token)`) to an arbitrary target chosen by the caller. There is no link between the assets being spent and the caller who supplies the transaction, so any tokens stranded by victims can be forwarded out by the next user. This is exactly the "Router-held balances are globally drainable" issue described in the sponsor notes.
