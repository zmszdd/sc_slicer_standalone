Anyone can mint LP tokens for free if `accrued fees > 0`

## Finding description and impact

Attacker Steals Accrued Launchpad Fees via Phantom Liquidity Mint/Burn (Reserves Exclude Fees While Balances Include Them)

**Root Cause**: In `_update` (lines 184-185), reserves are set to `balance - totalLaunchpadFee` to exclude accrued fees, but actual token balances still hold the fees. `mint` (lines 215-216) detects this excess as "added liquidity" without requiring transfers, minting free LP tokens proportional to the fees. `burn` (lines 248-249) then extracts the fees pro-rata from full balances (including excesses), stealing them before distribution.

https://github.com/code-423n4/2025-08-gte-perps/blob/f43e1eedb65e7e0327cfaf4d7608a37d85d2fae7/contracts/launchpad/uniswap/GTELaunchpadV2Pair.sol#L185-L188


**Impacts** (High Severity):
- **LP Dilution**: Phantom mints dilute existing LPs (e.g., ~0.01% per small exploit).


**Vulnerability Flow** (Simplified PoC Math, 10e18 Swap Input; Assumes Symmetric Fees, Initial Reserves=100e18, TotalSupply=100e18):
1. Swap 10e18 token0 in → ~9.066e18 token1 out; accrues fee0=1e16 (0.1% of input, prorated by launchpad LP share ~100%).
   - Balances: token0=110e18, token1=90.93e18.
   - Reserves: token0=109.99e18 (excludes fee0), token1=90.93e18.
   - Accrued: fee0=1e16, fee1=0 (same block, no distribution).

2. Immediate second swap (same block): 10e18 token1 in → ~10.86e18 token0 out; accrues fee1=1e16.
   - Balances: token0=99.13e18, token1=100.93e18.
   - Reserves: token0=99.12e18 (excludes total fee0=1.001e16), token1=100.92e18 (excludes fee1=1e16).
   - Accrued: fee0=1.001e16, fee1=1e16.

3. Attacker calls `mint(attacker)` (no tokens transferred in).
   - Excess: amount0=balance0 - reserve0 = 1.001e16; amount1=1e16.
   - Liquidity minted = min(1.001e16 * 100e18 / 99.12e18, 1e16 * 100e18 / 100.92e18) ≈ 9.908e15 LP tokens (pro-rata "free" share).
   - Attacker now holds 9.908e15 LP tokens.

4. Attacker transfers 9.908e15 LP to pair; calls `burn(attacker)`.
   - Burn calc: amount0Burn = 9.908e15 * 99.13e18 / (100e18 + 9.908e15) ≈ 9.821e15 (pro-rata full balance0).
   - amount1Burn ≈ 9.999e15 (pro-rata full balance1).
   - Transfers ~9.821e15 token0 and ~9.999e15 token1 to attacker (≈ accrued fees, minor rounding from skew).
