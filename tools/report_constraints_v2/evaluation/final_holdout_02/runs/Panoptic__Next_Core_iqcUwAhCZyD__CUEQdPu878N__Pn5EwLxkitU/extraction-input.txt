`BuilderWallet.init` is publicly callable and lacks any access control or one‑time guard. This allows any EOA to set `builderAdmin` after deployment and call `sweep` to drain all accumulated builder fees. The wallet is a custody point for protocol‑generated fee flow, so the impact is direct theft of builder‑split revenue and loss of incentive alignment for builders/referrers.
Any EOA can overwrite `builderAdmin` and sweep all builder fees from `BuilderWallet`, causing immediate loss of builder revenue.
