# A User Can Withdraw Tiny Amounts to Bypass Fees

## Finding Description and Impact

In the function `StakingManager::queueWithdrawal`, if a user passes an amount such that `amount * unstakeFeeRate < BASIS_POINTS`, the `kHYPEFee` is set to `0`:


This allows a user to bypass fees by withdrawing their stake in very small increments.

- **Likelihood**: Low – This vulnerability is unlikely to be exploited at scale, as the gas cost would exceed the value of the avoided fees.  
- **Impact**: High – Potential loss of protocol fees.
