`BalancerPriceOracle.getPrice()` uses raw spot reserves from `getPoolTokens()`, enabling instant flash-loan manipulation of oracle price

**Description:**

`BalancerPriceOracle.getPrice()` computes price directly from current pool balances:


`getPoolTokens()` returns the **current** pool balances which can be manipulated within a single transaction via flash loans + swaps. An attacker can:
1. Flash-loan large amounts of one token
2. Swap into the Balancer pool to shift reserves
3. Call any function that relies on `getPrice()` (e.g., `BuyBackBurner._buyOLAS()` which uses it for pre/post-swap validation)
4. Reverse the swap and repay the flash loan

The `getPrice()` function is used by `BuyBackBurner._buyOLAS()` for both the pre-swap check (`validatePrice`) and post-swap verification. An attacker can manipulate the spot price before and after the `buyBack()` call to satisfy both bounds while extracting value from the swap.

**Impact:**

Any contract relying on `BalancerPriceOracle.getPrice()` for trade execution, price validation, or collateral valuation can be exploited via flash loans. The oracle provides zero flash-loan resistance. Standard manipulation-resistant alternatives include Chainlink, Uniswap V3 TWAP, or Balancer V2's built-in oracle functionality.

**Recommended Mitigation:**

Use Balancer V2's built-in oracle (`getTimeWeightedAverage`) or Chainlink price feeds instead of raw spot reserves.
