# 阶段二开发复验：受控恢复与语义限定（2026-09-17）

这不是新的盲测，也不改写 [8 例首次测试](../fresh_holdout_01/REPORT.md)的 4/8 要素提取、1/8 完整形式化结果。Brix 已在旧批次出现，本次仅用于诊断。

## 改动与本地结果

- 新增可选 `--element-retries 1`：只在首步超时或 JSON 解析失败后重试一次，默认仍为零重试；每次尝试独立保存目录和状态。运行错误不自动重试，避免服务不可用时重复上传。第二步原有 `--formal-retries` 不变。
- 新增 `semantic-v3.12`：要求形式计划区分正常允许行为与报告所称的违规行为，保留 `without`、`unless`、`only if` 等限定；无法用现有谓词表达时标阻塞未决，不把核心坏结果悄悄降成次级影响。超时后将该提示段压缩，实际发送的早期文本留在运行目录 `prompt.txt`，当前文本未再外部调用。该版本**尚无模型语义效果证据**，不能称为准确率提升。
- 超时诊断现在只保存部分输出字节数和事件类型计数，不保存部分文本；可帮助区分完全无响应与生成中被截断。此功能在本次真实超时之后添加，所以历史超时没有这些计数。
- 离线控制证明现有 `condition_forbids_effect` 模式可区分“已获授权而完成操作”（允许）和“未获授权却完成操作”（违反）。这只证明表达能力，不证明模型会正确选择条件。
- 新增可选 `--lean-formal-input`：第二步仅发送已提取语句的 ID、文本、角色、模态和实体信息，不重复发送完整编号原文片段；Brix 的第二步 JSON 数据从 6606 字节降到 3632 字节（仅为本地大小对比，不能据此推断耗时或准确率）。本地保存的完整证据目录及程序校验不变。`semantic-v3.12` 的首步提示还收窄了 I：不把完整业务成功或建议修复误写成安全性质。[四例本地开发审查](LOCAL_SEMANTIC_AUDIT.md)说明了原因，但不构成独立标准。
- 255 项本地单元测试通过，其中新增 7 项覆盖重试、非重试错误、超时诊断、提示词隔离、轻量输入及上述逻辑控制。

## 一次真实复验

对 Brix 只取 `report.json` 标题、描述和影响；调用前用本地预览工具核对实际文本。使用旧批次保存的编号要素，单独运行 `semantic-v3.12` 第二步，不触及合约、PoC 或其他阶段。默认沙箱尝试在约 3 秒后以 `model runtime exit 1` 失败，分类为 `unknown_runtime_error`。允许网络后的独立尝试达到 240 秒上限，状态为 `TimeoutExpired`；两次均未产出形式计划或 Z3 结果。见 [第一次状态](brix_formal/status.json)和[第二次状态](brix_formal_escalated/status.json)。**因此不能比较 v3.11 与 v3.12 的准确性，也不能把本次算作流程成功。**

随后拟进行的轻量第二步真实调用被权限审查拒绝：它会上传从报告派生的 P/I/V、实体和歧义内容，而现有授权被认定只覆盖报告标题、描述、影响原文。没有绕过审查，也没有进行该次外部调用；`--lean-formal-input` 目前只有离线测试。后续如需真实验证，须明确授权这些衍生数据的外传。
新增[本地精确预览工具](../../preview_formal_input.py)，可在不调用模型的情况下打印将送入轻量第二步的 JSON 数据，供逐项核对授权范围。

## 方法依据与下一步

[SpecGen](https://arxiv.org/abs/2401.08807)说明形式规格的可验证性与语义完整性是不同难题；[Attribute or Abstain](https://aclanthology.org/2024.emnlp-main.463/)提示复杂回答的证据归属仍会出错。因此保留编号证据、允许弃权，并把 Z3 的内部一致性与报告语义忠实度分开记录。OpenCode 的[CLI 文档](https://opencode.ai/v2/docs/cli/commands/)确认 `--format json` 产出的是用于脚本处理的事件流；它本身不保证模型文本一定是符合本项目 schema 的完整 JSON。

无报告内容的短连通性请求在可访问环境中约 10 秒返回，说明服务并非完全不可用；长形式化请求的稳定性仍未解决。不要重复无上限调用。获得衍生语义数据的明确外传授权后，才可在另一个新批次以固定预算测试轻量模式，并与 v3.11 开发基线分开统计：首步 JSON 成功率、第二步完成率、P/I/V 证据支持与语义限定保留率。人工或独立审核之前不得发布“准确率”。
