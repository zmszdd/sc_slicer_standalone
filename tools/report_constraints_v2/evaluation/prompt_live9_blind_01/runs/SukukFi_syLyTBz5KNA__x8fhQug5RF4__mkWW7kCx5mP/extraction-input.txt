Vault can be removed despite having pending redeems

## Finding description and impact

There exists a sequence of actions by the user where a pending redeem request can be ignored by the Owner when setting vault inactive and unregistering the vault.

This happens because of a missing pendingRedeemCheck and a flow of execution where, the `activeRedeemRequestersCount` can be made 0 despite a pending redeem request.
