Missing Start Timestamp Validation in Campaign Creation

## Summary 

The `DistributionCreator` contract lacks validation to ensure that campaign start timestamps are reasonable (example : `startTimestamp >= block.timestamp`). This allows users to create campaigns with past start times, including campaigns that have already completely ended before creation

## impact 

Users pay full fees and token amounts for campaigns that can never distribute rewards


## Fix

Consider enforcing `startTimestamp + duration > block.timestamp` or at least `startTimestamp >= block.timestamp` to prevent funding dead campaigns.
