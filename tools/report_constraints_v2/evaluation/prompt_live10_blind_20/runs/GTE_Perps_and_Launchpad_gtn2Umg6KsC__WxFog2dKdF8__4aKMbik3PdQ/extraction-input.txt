The address of the pair created by the createPair() function in GTELaunchpadV2PairFactory.sol and the pair address predicted by the pairFor() function in Launchpad.sol may not match.

## Finding description and impact

The address of the pair created by the createPair() function in GTELaunchpadV2PairFactory.sol and the pair address predicted by the pairFor() function in Launchpad.sol may not match.

### Description
The createPair() function in GTELaunchpadV2PairFactory.sol uses four addresses to calculate the salt value, whereas the pairFor() function in Launchpad.sol uses only two addresses for the same calculation. 
Consequently, the pair addresses computed by these two functions can never match.


### Impact

When the totalFeeShare of a launchToken becomes zero, the endRewards() function in Launchpad.sol is called. 
In this function, pairFor() is used to predict the pair address. However, since the predicted address will not match the actual deployed pair address, the function will attempt to interact with a non-existent contract, leading to a revert. 
This failure prevents the endRewards functionality from being executed correctly.
