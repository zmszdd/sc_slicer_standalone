Last pending deposits or withdrawals will fail if there are number of items in pending array

## Finding description and impact

There are 4 deletes on storage array, on 2 unique variables.


In solidity, deleting array works by assigning zero values to all existing elements then setting length to 0. To be specific, with 300 elements being pushed, it exceeds 2M gas (small block limit). Similarly, with 5000 elements, it also exceeds 30M gas (big block limit).

This delete is done when the last item on the queue. (regardless of batch size; it also happens when batchSize=1) That means it'll always happen with normal flows of operation. The operation will not work until another user pushes one more operation and batchSize is set less then the pending operations.
