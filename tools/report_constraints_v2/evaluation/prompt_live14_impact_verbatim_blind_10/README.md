# semantic-live-14 verbatim Impact blind test

Ten fresh reports are selected by unseen case ID, report hash, and normalized input hash. Selection occurs before model calls and does not inspect Impact content. The run uses the current `semantic-live` pipeline, the restricted marked-Impact catalog, verbatim evidence enforcement, DeepSeek `deepseek-flash`, concurrency 2, and the same retry/formalization settings as the prior live13 evaluation.

The selected manifests and run outputs are frozen in this directory.
