UniswapPriceOracle TWAP validation is broken - always returns true regardless of price manipulation

## Summary

The `UniswapPriceOracle.validatePrice()` function contains a mathematical flaw where the calculated Time-Weighted Average Price (TWAP) always equals the current spot price. This renders the pre-swap slippage protection ineffective, allowing attackers to manipulate the Uniswap V2 pool price via flash loans before calling `BuyBackBurner.buyBack()`, causing the protocol to purchase OLAS at inflated prices.

## Vulnerability Detail

The `validatePrice()` function in `UniswapPriceOracle.sol` attempts to calculate a TWAP to compare against the current spot price for slippage validation. However, the implementation has a fundamental flaw:

## Impact

- **Protocol fund loss**: Attackers can manipulate Uniswap V2 pool prices via flash loans BEFORE calling `buyBack()`, causing the protocol to purchase OLAS at inflated prices
- **Severity**: The pre-swap TWAP validation is completely non-functional - `validatePrice()` always returns `true` regardless of manipulation
- **Affected contracts**: `BuyBackBurner.sol`, `BuyBackBurnerUniswap.sol` when using `UniswapPriceOracle`

**Note on existing mitigations**: `BuyBackBurner._buyOLAS()` has a second check comparing price before and after the swap. However, this does NOT protect against pre-manipulation attacks because:
- `previousPrice` is captured AFTER the attacker's manipulation
- The swap executes at the manipulated price
- `tradePrice ≈ previousPrice` (both are manipulated), so the check passes

**Attack Flow:**
1. Attacker takes flash loan (e.g., large amount of secondToken)
2. Swaps to manipulate Uniswap V2 pool reserves (increases OLAS price by 10x)
3. Calls `BuyBackBurner.buyBack()`
4. `validatePrice()` returns `true` (broken TWAP = manipulated spot price)
5. `previousPrice` = manipulated price (10x)
6. Protocol swaps at inflated price
7. `tradePrice ≈ previousPrice` → after-swap check passes
8. Protocol receives far less OLAS than fair value
9. Attacker reverses manipulation and repays flash loan
