Gauge admin can indefinitely lock stakers' NFTs via `withdraw`

## Summary
The missing emergency exit in `contracts/CLGauge/GaugeCL.sol:188` will cause an indefinite loss of access for CL gauge stakers as the gauge admin can toggle emergency mode and block the only withdraw path.

## Root Cause

In `contracts/CLGauge/GaugeCL.sol:188` the `withdraw` function is guarded by the `isNotEmergency()` modifier, and there is no alternative withdrawal route exposed to users while `emergency` is `true`. This differs from the V2 gauge design, where `emergencyWithdraw` remains callable during emergencies. As a result, once `emergency` is activated, every user withdrawal reverts and NFTs remain custodied by the gauge until governance clears the flag.

## Vulnerable path

This modifier blocks any function when `emergency` is active.

When stakers call `withdraw`, the modifier executes first; if `emergency` is `true`, the call reverts before the NFT can be returned.

The gauge owner (governance) can flip `emergency` on at any time, permanently trapping all staked NFTs until they later call `stopEmergencyMode`.

## impact

Users cannot recover their liquidity NFTs while emergency mode is active, leaving funds inaccessible for the entire pause window.
