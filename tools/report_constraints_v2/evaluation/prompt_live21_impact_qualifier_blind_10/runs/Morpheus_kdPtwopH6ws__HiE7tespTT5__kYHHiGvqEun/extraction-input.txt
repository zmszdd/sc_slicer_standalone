Aave Merit rewards not accounted in claimAaveRewards()

## Finding description
Aave’s new **Merit Rewards program** distributes incentives via a **Merkle-based claim system** (through [Merkl](https://app.merkl.xyz)) instead of the standard `RewardsController`.

According to aave documentation:

>Merit Program Merit is an Aave-alignment user reward system, designed as a merkle-tree-based periodic airdrop to incentivise Aave-aligned behaviours and enhance the competitiveness of the Aave protocol. More information and interface to access merit distribution can be found [here](https://apps.aavechan.com/merit).

Currently, `Distributor::claimAaveRewards()` only calls:


and does not account for Merit rewards, which would need to call `Claim()` on `Angle Protocol: Distributor`.

As a result, users may **miss out on unclaimed Merit rewards**, which expire after **6 months**, leading to permanent loss. Since users could reasonably assume all rewards are handled by `claimAaveRewards()`, this creates a usability and value loss risk.
### Severity

- **Impact: Medium** — Users can permanently lose rewards.
- **Likelihood: Medium** — Merit campaigns are active and many users qualify.
