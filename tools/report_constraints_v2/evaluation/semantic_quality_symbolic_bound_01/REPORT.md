# 报告内符号幂数值门修正

日期：2026-10-20。类型：离线代码修正与机制回归；未调用模型。

## 发现

`prompt_live5_fidelity_01` 的 Covenant 报告在同一条前提中写明：
`marketBaseTokenSupply <= 2^noCapLimit`，并给出 `noCapLimit = 60`。模型保留了
`power_of_two(60)`。旧数值门只识别数字指数形式，因此把 `<= 2^noCapLimit` 的 `2`
误读成字面上界 `<= 2`，拒绝了这条有报告依据的规格。

## 修正

- 识别比较运算符后的 `2^变量` 形式，并只使用同一条报告前提中唯一、明确的整数赋值解析变量。
- 支持可选整数偏移，例如 `2^limit - 1`。
- 在一般数值字面量扫描前遮蔽完整幂表达式，避免把基数 `2` 当成比较上界。
- 指数缺少绑定或存在冲突绑定时保留为不可解析项，数值门继续拒绝；不猜测指数值。
