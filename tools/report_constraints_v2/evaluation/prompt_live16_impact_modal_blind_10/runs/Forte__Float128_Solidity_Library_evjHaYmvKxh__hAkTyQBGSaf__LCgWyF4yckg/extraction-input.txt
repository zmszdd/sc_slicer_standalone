Two Equally packed negative floats incorrectly evaluated as unequal by `ge` function when one of them uses L Mantissa

## Finding description

The [`Float128::ge`](https://github.com/code-423n4/2025-04-forte/blob/4d6694f68e80543885da78666e38c0dc7052d992/src/Float128.sol#L1013) function is designed to take two floats of either of the possible Mantissa (M or L) and return true if the former float is greater than or equal to the later.

However, there is an issue which arises when any one of the two given packed float contains a L Mantissa and both of the given fixed floats have the `MANTISSA_SIGN` set to negative. This happens due to the `lt(aMan, bMan)` check when comparing for two negative fixed floats:

This is not correct because a `greater than equal to` function should also consider when two negative packed floats are equal.


## Impact

1. Would return false for equal values when both fixed floats are negative and any one of them has L Mantissa flag set.
