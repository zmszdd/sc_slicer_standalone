Bootstrap shares dilute user profits by participating in yield distribution

## Description:
The HypoVault contract initializes 1,000,000 bootstrap shares in its constructor that belong to no user but participate in profit distribution calculations. These "virtual" shares are included in the totalSupply used for share-to-asset conversion ratios during withdrawals, causing them to implicitly claim a portion of vault profits despite not representing any actual user deposits.

## Attack path:
1. HypoVault is deployed with 1,000,000 bootstrap shares in totalSupply
2. Users deposit funds and receive legitimate shares proportional to their deposits
3. Vault generates profits through manager operations
4. When users withdraw, the conversion rate calculation includes bootstrap shares in totalSupply
5. Bootstrap shares effectively "claim" their proportional share of vault profits
6. User returns are diluted by the percentage that bootstrap shares represent of total supply

## Impact:
Users suffer permanent loss of yield proportional to bootstrap shares' percentage of total supply
