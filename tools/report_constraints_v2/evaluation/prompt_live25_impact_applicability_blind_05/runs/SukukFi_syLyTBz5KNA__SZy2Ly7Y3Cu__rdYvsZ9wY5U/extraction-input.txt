Anyone can drain the WERC7575Vault.sol contract

## Finding description and impact
The investment Vault has self approval check. Where the users can't approve themselves. Only the `validator` address can approval them using `WRC7575ShareToken::permit()` method. Once approved, the `withdraw()` or `redeem()` can be called. But there is no validation on the `msg.sender` or the `receiver`. 

So anyone can drain any vault as long as there is some address that have self approval. So, as soon as the `validator` gives the self approval, anyone can execute the `withdraw()` or `redeem()` and take the assets out to their own address.
