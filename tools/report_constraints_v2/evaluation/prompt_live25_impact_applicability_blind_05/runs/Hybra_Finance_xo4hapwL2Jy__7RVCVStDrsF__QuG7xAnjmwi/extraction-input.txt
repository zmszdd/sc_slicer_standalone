gHYBR mints too few shares on deposit by using post-deposit totalAssets, causing systematic depositor value loss

The `GovernanceHYBR.deposit()` function calculates shares using `totalAssets()` that already includes the new deposit, resulting in systematic under-minting of shares to depositors. The function adds HYBR to the veNFT (increasing `totalAssets`) before calling `calculateShares()`, causing the share calculation to use an inflated denominator. This transfers value from new depositors to existing shareholders on every single deposit.
