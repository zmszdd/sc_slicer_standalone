Missing Access Control in BuilderWallet.init() Function

## Finding description and impact

The `BuilderWallet.sol` contract contains a critical access control vulnerability in the `init()` function that allows any address to overwrite the `builderAdmin` at any time. The core issue is that the `init()` function lacks any permission checks, making it publicly callable by anyone.

According to the contract design, `BuilderWallet` is deployed by `BuilderFactory` to manage fee distribution for builders. The `init()` function is intended to set the `builderAdmin` address, which has exclusive permission to call `sweep()` and withdraw tokens from the wallet. However, the implementation allows any address to call `init()` and overwrite the legitimate `builderAdmin`.
