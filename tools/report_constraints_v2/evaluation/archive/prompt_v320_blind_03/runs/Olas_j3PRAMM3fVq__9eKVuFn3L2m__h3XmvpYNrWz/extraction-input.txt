Uniswap TWAP calculation collapses to spot price

## Summary
The `validatePrice()` function in `UniswapPriceOracle` incorrectly calculates the time-weighted average price (TWAP), resulting in the derivation always being zero. This renders the slippage protection mechanism completely ineffective, allowing any trade to pass validation regardless of price manipulation.

## Impact Explanation
This vulnerability completely bypasses the oracle's slippage protection mechanism.

An attacker can manipulate the spot price through flash loans or large trades, and `validatePrice()` will still return `true`, allowing the manipulated price to be accepted.

## Likelihood Explanation
This issue will occur every time `validatePrice()` is called.
