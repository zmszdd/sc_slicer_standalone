# semantic-live-12 分步 Impact 清单盲测

## 设计

模型调用前冻结了 10 份未见报告。按历史 case ID、报告哈希和规范化输入哈希排除旧样本；选样时不检查 Impact 区域是否存在或其内容。DeepSeek Flash 配置与前一轮相同。提取阶段共记录 91 次模型调用。

新流程先把显式 Impact 区域证据 ID 切成独立目录，仅用该目录生成影响清单；核心提取另行生成 P/I、原因和步骤，丢弃并留档其中误产的影响项；再合并经来源校验的清单，逐项生成 P/I/V。无明确伤害结果时不启动规则化，报告保留为待影响项复核。

## 结果

| 指标 | 结果 |
| --- | ---: |
| 冻结并运行报告 | 10/10 |
| 候选检查通过 | 5/10 (50%) |
| 待影响项复核 | 2/10 |
| 其他需要复核 | 3/10 |
| Impact 来源越界拒绝 | 0/10 |
| 有规则评估结果 | 8 份报告、22 个已识别影响项 |
| 完整 P/I/V | 9/22 (40.9%) |
| 所有已识别影响项都完整的报告 | 2/8 (25%) |
| 候选 P/I/V 盲审忠实 / 弱化 / 不忠实 | 3 / 2 / 0（5 份报告） |
| 零调用重放通过 | 10/10 |

两份待影响项复核报告的 Impact 区域只描述了原因或机制，没有明确写出伤害结果，因此没有推测影响项。另有 5 份清单带有歧义/遗漏说明，其中包括截断片段、条件或“尚未发现直接盗取路径”等限定；这类说明与 P/I/V 是否完整分别记录。

盲审覆盖 9 条候选公式的 27 个 P/I/V 角色：24 项完全支持、3 项部分支持，没有评为不忠实。评审与生成使用同一模型族，不能作为独立人工金标准。

## 判断

本轮没有出现 Impact 证据越界拒绝、来源校验重试，也没有核心提取器误产后被丢弃的影响项；输入构造和离线重放均验证了影响提取器只收到标注区域内的证据。这说明来源边界从事后拒绝前移到了提取输入。

规则化完整率仍约为四成，且仅 2/8 份有影响项的报告覆盖了全部已识别影响项。候选通过率为 5/10，盲审有 2/5 报告存在表达弱化。上一轮为另一组报告，不能据此作严格的配对提升结论；当前只能确认结构性越界问题得到控制，覆盖与语义忠实度仍需继续改善。
