Logical Error in Mint Cap for Small Markets (_checkMintCap)

## Finding description and impact

A logical error in the `_checkMintCap` function within the `LatentSwapLogic.sol` library effectively disables the minting cap for small markets. The function uses a logical AND `(&&)` operator where a logical OR `(||)` is required, allowing users to mint tokens far in excess of the intended limits. This can be exploited to manipulate market prices, create worthless synthetic tokens, and potentially drain 
value from the protocol.

## Vulnerability 
The `_checkMintCap` function is designed to limit the size of a single mint operation relative to the market's total size. For small markets `(where marketBaseTokenSupply <= (1 << noCapLimit))`, the intention is to prevent a mint that is either larger than the current supply or larger than a very high absolute limit `(FixedPoint.Q96)`.
