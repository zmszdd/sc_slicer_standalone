Not compliant with EIP7575

## Finding description and impact

The `ShareTokenUpgradeable` contract states in its natspec that it is fully EIP 7575 compliant as the share token of the multi-asset vault system but this is not the case. The EIP 7575 specification declares:
> The share contract SHOULD implement the ERC-165 supportsInterface function. The share token MUST return the constant value true if 0xf815c03d is passed through the interfaceID argument.

As `ShareTokenUpgradeable` does implement the supportsInterface function, it must return true for the constant value `0xf815c03d` passed in as the interfaceID, but it returns false instead. This would lead to integration errors with external systems that depend on this feature.
