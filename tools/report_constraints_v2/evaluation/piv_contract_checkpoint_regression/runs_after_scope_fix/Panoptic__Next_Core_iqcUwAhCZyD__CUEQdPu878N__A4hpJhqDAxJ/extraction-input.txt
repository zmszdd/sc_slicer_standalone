Missing Access Control in BuilderWallet.init() Allows for Account Takeover and Theft of All Builder Fees

### Description
The `init()` function in the `BuilderWallet` contract lacks any access control checks. This allows any arbitrary user to call the function and overwrite the `builderAdmin` address repeatedly.

https://github.com/code-423n4/2025-12-panoptic/blob/fe557748210a529ae414d7c487b6514be0d9e220/contracts/RiskEngine.sol#L2315-L2317


 An attacker can take over the `builderAdmin` role and use the `sweep()` function to drain all tokens from the `BuilderWallet`.


## Impact

Loss of Funds.

## Mitigate 
Add access control và initialization check
