## H-01 — BuilderWallet `init()` is permissionless and can be re-run to seize admin and steal funds

**Severity:** High

### Impact

Any unprivileged attacker can become `builderAdmin` for any deployed BuilderWallet and steal all ERC20 tokens held by that wallet (e.g., builder fee/commission receipts).

### Exploit narrative (attack steps)

Assumptions:
- A BuilderWallet exists (deployed by BuilderFactory) and holds ERC20 tokens.

Steps:
1. Call `BuilderWallet.init(attacker)`.
2. Call `BuilderWallet.sweep(token, attacker)` for each token held.
