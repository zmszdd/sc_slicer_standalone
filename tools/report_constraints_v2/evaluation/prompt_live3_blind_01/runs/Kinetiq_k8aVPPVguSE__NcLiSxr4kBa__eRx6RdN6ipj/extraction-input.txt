StakingManager.sol#redelegateWithdrawnHYPE() could revert due to incorrect _cancelledWithdrawalAmount calculation

## Finding description and impact

cancelled withdraw amount will be recorded to _cancelledWithdrawalAmount, then manager role could redelegate withdrawn HYPE that was previously cancelled, amount is _cancelledWithdrawalAmount. It should be noted that, one stake could be withdrawn and then cancel, for multiple times, which make _cancelledWithdrawalAmount greater than the actual cancelled amount. This could cause address(this).balance < _cancelledWithdrawalAmount, then redelegateWithdrawnHYPE() will revert.
Besides, there are fees in cancelled request, which should also be redelegated.
