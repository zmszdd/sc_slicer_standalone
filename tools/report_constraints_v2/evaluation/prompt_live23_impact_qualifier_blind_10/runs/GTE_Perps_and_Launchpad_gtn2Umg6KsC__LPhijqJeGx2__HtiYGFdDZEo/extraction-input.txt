User can withdraw all their margin and back the position with only positive uPNL, avoiding paying liquidation fee to the liquidators or to the insurance fund

### Description and Impact 
If a position has high enough pnl, a user can withdraw their initial margin via the `removeMargin` function. The `assertPostWithdrawalMarginRequired` check can be easily bypassable as it takes into consideration the total equity of a position while checking for the min margin required for the user's current position. Now, the user can just free-ride their position as their margin is safe, if the position goes into a loss and gets liquidatable, the user avoids paying any fees to the protocol since the liquidaton fee is settled on the user margin but it would be zero, as well as, the entire negative pnl becomes the total bad debt that has to be covered entirely by the protocol's insurance funds. And in case of backstop liquidations, not only the user avoids liquidation fees but also any rewards for the backstop liquidators.
