# gold-v1 与 semantic-v3.7 实施进度

日期：2026-09-16。

## 已完成

1. 建立五份公开、非敏感真实报告输入快照，排除 PoC、修复建议和合约代码。
2. 为每份报告给出 P、I、V、逻辑骨架、模态、证据锚点、预期 unresolved 和次级影响。
3. 建立 25 项人工审核卡；未全部确认时不能生成批准记录。
4. 建立绑定模型输出哈希的人工评分模板和评分脚本；未人工批准时拒绝计算准确率。
5. 新增 `semantic-v3.7`：unresolved 包含类别、描述、来源 ID 和阻塞标志。
6. 非阻塞 unresolved 仅进入 `unresolved-review.json`，不再自动污染 claim。
7. 明确禁止把“符号地址无具体值”“布尔结果无数值定义”“尚未代码绑定”作为 unresolved。
8. v3.5/v3.6 历史 schema 和离线重放保持兼容。

## 盲测已完成

- 用户已明确授权五份公开报告用于指定模型的 v3.7 盲测。
- 5/5 完成第一步；2/5 完成形式化、SMT/Z3 和离线重放。
- 其余三例分别为空 JSON 响应、第二步超时、数值单位/schema 错误。
- 原始输出无重试、无修补，见 `BLIND_REPORT.md`。

## 尚未完成

- `REVIEW.md` 仍为 0/25 人工确认，所以当前草案不是已批准金标准。
- 助手初评已保存，但评分程序会拒绝把它当成人工评分。
- 因此目前没有也不应宣称 v3.7 的可信语义准确率；40% 只是技术链完成率。

## 完成准确率评测需要的两项输入

1. 人工审核 `REVIEW.md`，修订不认可的答案，将认可项改成 `[x]`，然后运行
   `approve_gold.py --reviewer NAME`。
2. 对冻结的盲测输出填写并人工确认 ratings；每项评分必须绑定结果文件哈希。
