UniswapPriceOracle TWAP Always Equals Spot Price

### Finding Description and Impact

The `validatePrice()` function in `UniswapPriceOracle.sol` is intended to compute a TWAP and reject transactions where the current price deviates too much from the time-weighted average. However, the TWAP formula self-cancels, always yielding the current spot price. This makes the oracle check completely useless as price manipulation protection.

Algebraic simplification:


The `cumulativePriceLast` is added and then subtracted, cancelling entirely. The TWAP always equals the current spot price (`tradePrice`), so the derivation at L86-88 is always 0.
