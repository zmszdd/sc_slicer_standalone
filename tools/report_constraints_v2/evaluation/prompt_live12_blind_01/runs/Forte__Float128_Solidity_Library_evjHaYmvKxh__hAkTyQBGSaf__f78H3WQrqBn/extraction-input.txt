Equal packed floats incorrectly evaluated as unequal by `ge` function when one of them uses L Mantissa

## Finding description

The [`Float128::ge`](https://github.com/code-423n4/2025-04-forte/blob/4d6694f68e80543885da78666e38c0dc7052d992/src/Float128.sol#L1013) function takes in two packed floats, which is then used to compare if the former packed float is greater than or equal to the later.

However, there is an issue which arises when any one of the given packed float contains a L Mantissa, which happens due to the way we determine the `retVal` via a less than check `lt(bMan, aMan)`.

This is not ideal because a `greater than equal to` function should also consider when two packed floats are equal, which is lacking here.

1. This could lead to returning false for some equal values.
