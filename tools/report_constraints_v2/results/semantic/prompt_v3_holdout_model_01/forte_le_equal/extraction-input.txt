## Finding description

The [`Float128::le`](https://github.com/code-423n4/2025-04-forte/blob/4d6694f68e80543885da78666e38c0dc7052d992/src/Float128.sol#L899) function has the responsibility of taking in two packed floats, which is then used to compare if the former packed float is less than or equal to the later.

However, there is an issue which arises when any one of the given packed float contains a L Mantissa, which happens due to the way we determine the `retVal` via a less than check `lt(bMan, aMan)`.

This is not ideal because a `less than equal to` function should also consider when two packed floats are equal, which is lacking here.
