## Finding description and impact
The `updateImpact` function in the `ServiceNft` contract lacks access control, allowing any external address to modify critical impact and maturity values. This function updates `_impacts` and `_maturities` state variables and emits events that may influence system-wide calculations. Attackers could exploit this to arbitrarily alter scores, leading to incorrect data integrity, unfair rewards, or protocol manipulation. The absence of restrictions poses a high risk as core metrics can be tampered with by unauthorized parties.
