# Missing Caller Authorization in WERC7575Vault Enables Unauthorized Fund Theft

## Severity

**HIGH**

## Summary

The `withdraw()` and `redeem()` functions in `WERC7575Vault.sol` accept an arbitrary `owner` parameter but only verify the owner's self-allowance via `spendSelfAllowance()`. They fail to check whether `msg.sender` is authorized by the owner, allowing any external account to steal funds from any user with active self-allowance.

## Vulnerability Detail

The vault's withdrawal functions violate the ERC-4626 specification by omitting caller authorization:


The function accepts any `owner` address from any caller and only verifies that the `owner` has self-allowance (platform permission). There is no check that `msg.sender == owner` or that `allowance[owner][msg.sender] >= shares`.

Per ERC-4626, when `msg.sender != owner`, the vault MUST verify caller authorization. This check is completely absent.
