### Description

`_validateSignature()` strips an optional `(validUntil, validAfter)` suffix from `userOp.signature`, but it only recovers the signer over `userOpHash`. Under ERC-4337 the EntryPoint hash excludes the signature bytes entirely, so a relayer can keep the same 65-byte ECDSA signature and rewrite the trailing validity window without invalidating the signature.

### Impact

A malicious bundler can execute an otherwise valid user operation earlier than `validAfter` or long after `validUntil`, bypassing the signer’s intended timing constraint. Any wallet action encoded in that user operation can then execute outside the user’s approved window.
