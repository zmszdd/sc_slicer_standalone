## Summary
`BuyBackBurner.transfer(address token)` can be called by anyone and transfers the entire balance of token held by the buyback contract:
- if `token == olas` → sends all OLAS to `bridge2Burner`
- else → sends all of token to `treasury`
Since `buyBack(secondToken, ...)` requires the contract to hold `secondToken` inventory and reverts on zero balance, an attacker can front-run/race and sweep inventory immediately before a keeper’s buyback, causing the keeper tx to revert with `ZeroValue()`.

And `buyBack` reverts when there is no inventory:
## Impact
- Reliable griefing of buyback operations (keepers waste gas; buybacks delayed/blocked).
- Forces routing of non-OLAS inventory to treasury, potentially preventing intended “inventory → buy OLAS → bridge2Burner” cadence.
