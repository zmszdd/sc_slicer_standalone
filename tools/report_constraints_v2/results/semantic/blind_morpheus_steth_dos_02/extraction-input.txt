Aave supply DoS due to stETH 1-wei transfer discrepancy in `Distributor.supply`

## Finding description and impact
When a user stakes stETH, the flow is:

1. `DepositPool.stake()` → `Distributor.supply(depositPoolAddress, amount)`
2. `Distributor.supply` pulls `amount` from the `DepositPool` and then calls Aave `supply` with the same `amount`.

The implementation assumes transfer-in equals `amount`. For stETH, due to the known 1 wei discrepancy on transfer, the distributor’s actual balance increases by `amount - 1`. It then instructs Aave to pull `amount`, which exceeds the distributor’s actual balance by 1 wei, so Aave’s `supply` reverts.

### Impact

Staking with stETH is effectively DoS’d; transactions revert.

## Recommended mitigation steps

Treat stETH as a fee-on-transfer/deflationary-like token pattern. Use balance delta to determine the actual received amount, then pass that to Aave.
