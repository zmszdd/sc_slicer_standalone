## Finding description and impact

The `Distributor._claim()` function incorrectly supplies the cumulative entitlement `(amount)` to the onClaim callback rather than the actual transferred amount `(toSend).` After the first claim, these values diverge, causing integrating protocols to operate on incorrect token amount assumptions.

## Impact
Any contract relying on the amount parameter for reward accounting will receive incorrect values after the first claim. This can cause state desynchronization, incorrect reward distribution, or loss of funds in downstream protocols.
