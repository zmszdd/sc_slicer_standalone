## Finding description and impact
The endRewardsAccrual()  function in GTELaunchpadV2Pair.sol contains a critical access control vulnerability due to an inverted condition check that completely undermines the intended permission system. The function use ```if (msg.sender != launchpadFeeDistributor) revert("GTEUniV2: FORBIDDEN")```
which incorrectly allows the legitimate distributor address to execute the function while potentially permitting unauthorized addresses to bypass access controls. This inversion creates a dangerous security flaw where the access logic operates in direct opposition to its intended design, enabling unexpected function execution paths. The impact includes potential unauthorized deactivation of rewards accrual, disruption of protocol reward distribution mechanisms, and establishes a concerning pattern of access control failure that could be exploited in other parts of the contract system. While current implementation details may prevent full exploitation, the fundamental logic error poses significant risk to protocol integrity and requires immediate remediation.
