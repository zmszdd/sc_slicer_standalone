# v3.15 开发回归摘要

开发集使用既有错误案例 OLAS、Merkl、Panoptic，只用于定位与修复，不计入独立准确率。

- Panoptic：`monotonicity` 分类与 before/after 公式正确，且精确保留 `2^127-1`、
  `2^106-1`；一次模型调用完成。
- Merkl：`state_correspondence` 分类正确，恒真 `x==x` 已被新增确定性规则拦截；最终候选的
  I/V 对应事件字段，但 P 又引入报告未明确断言的地址不等式，因此仍只能算 partial。
- OLAS：模型多次偏向“少收到 OLAS”的下游价值影响，最终产物声明核心关系缺少定义并
  阻止继续；这是安全降级，但没有解决“优先选择直接否定 I 的检查结果”。

开发回归说明 v3.15 已解决分类覆盖、精确幂常量、类型错误、未声明变量和显式恒真式等
工程问题；剩余瓶颈是跨分支拼接、P 来源蕴含和安全意图被弱化，必须由独立语义复核处理。
