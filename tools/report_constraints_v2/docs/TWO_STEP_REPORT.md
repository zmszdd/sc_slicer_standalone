## 拒绝原因

模型为 integrator 给出引文，开头为 `Integrators can: 1. Call ...`，并将两个列表项拼成单行。原文是含 `so that integrators can:` 的段落与分行列表，这一生成引文不是逐字连续复制。

这不一定意味着 integrator 实体本身错了，但违反当前精确证据要求，不能作为可追溯原文引文接受。诊断扫描发现这一条不匹配证据；因为验收首先拒绝证据，不据此保证其他字段全部正确。

另外，模型把 exact-fee 测试成功作为 impact，并有设计意图落在 assumption 的情况；原文测试对照、坏效果、设计意图仍需进一步区分，不能只修正引文就称语义全部正确。
